Look up a live stock quote

A small companion tool for the Excel to Python for Finance course — enter a ticker to pull a live quote via the Alpha Vantage API.

Your Alpha Vantage API key

Free keys are available at alphavantage.co. Your key is stored only in this browser (localStorage) — it is never sent anywhere except directly to Alpha Vantage, and it is not part of this site's source code.

Get a quote

Enter a ticker symbol, e.g. AAPL, MSFT, TSLA, VOD.L.

Free-tier Alpha Vantage keys are limited to 25 requests per day and roughly 5 per minute. If a lookup fails, wait a moment and try again.
